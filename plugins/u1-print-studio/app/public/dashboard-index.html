Printer widgets

Open a focused view. Availability describes this release, not printer status.

  • Progress

    Implemented

    Print state, progress, layers and remaining time.

  • Camera

    Implemented

    Snapshots and live view.

  • Thermals

    Partial

    Extruder and bed temperatures. Chamber readings are not implemented yet.

  • Heads & Filaments

    Partial

    Head state and temperatures. Filament material and color are not implemented yet.

  • Jobs

    Partial

    Current-job details. Job history is not implemented yet.

  • Queue

    Not implemented

    View available; queue data is not implemented yet.

  • Fans

    Not implemented

    View available; fan and purifier readings are not implemented yet.

  • Bed Mesh

    Not implemented

    View available; bed-mesh data is not implemented yet.
