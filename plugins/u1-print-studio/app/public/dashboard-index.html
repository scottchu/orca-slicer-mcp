Printer widgets

Open a focused view. Availability describes this release, not printer status.

  • Progress

    Implemented

    Print state, progress, layers and remaining time.

  • Camera

    Implemented

    Snapshots and live view.

  • Thermals

    Partial

    Extruder and bed temperatures. Chamber readings are not implemented yet.

  • Heads & Filaments

    Partial

    Head state, temperatures and printer-reported filament vendor, material, color and presence. Independent filament sensors remain unavailable.

  • Current Job

    Partial

    Current filename and storage details only.

  • Job History

    Not implemented

    View available; job history is not implemented yet.

  • Queue

    Not implemented

    View available; queue data is not implemented yet.

  • Fans

    Not implemented

    View available; fan and purifier readings are not implemented yet.

  • Bed Mesh

    Implemented

    Reported probe grid, bounds and height range.
