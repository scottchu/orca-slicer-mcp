# Composition spacing — 2026-09-06

## Scope and result

User feedback identified excessive spacing between attributes of the same subject.
The candidate keeps Smart's same four attributes, values, labels, theme, ordering
and wire contract. Compact grid retains its two-field subset. The scoped design
change is recorded in decision 0053 and the current design contract.

At 390 CSS px / root 16px, the final Smart temperature-to-secondary-label gap is
24.03125px (baseline 60.734375px); card height is 213.1484375px (baseline
290.546875px). Compact's visible inter-attribute gap is 8px (baseline 40px).
These are current-run browser measurements, not values inferred from CSS.
The final 320px / root 32px capture retains readable wrapping and atomic target/unit.
The outer Lab stage no longer reserves an unused 330px floor after the card shrinks.

The preliminary 188px card / 14px gap candidate was rejected: valid long decimal
values could need a second line after its width-only one-line temperature rule.
Actual private MCP HTML with valid 499.999999 / 499.999999 values reproduced
28.796875px and 57.59375px error/ready height differences at 100%/200%.
Temperature now retains two structural lines; no precision, data or schema is
changed. Quiet fan values retain the width-aware reserve for their closed vocabulary.
