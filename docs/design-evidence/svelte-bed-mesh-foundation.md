# Svelte Bed Mesh foundation design evidence

The selected target is the existing white U1 focused-card language with one
specific correction from the user's 2026-08-31 phone review: 2D and 3D must
occupy the same vertical space. The supplied 2D capture showed a readable square
height map; the supplied 3D capture showed a nearly blank, compressed surface
and a different chart height. The earlier Fluidd reference contributes the
orbitable XYZ surface, visible Z scale and real height shape, but not its dark
dashboard, profile controls, prose or unrelated panels.

The candidate therefore uses one 4:3 chart frame, one data set and one palette
for both modes. The fixed user-visible hierarchy is title/time, reported-grid
identity, chart, compact Z legend, three numerical facts and bottom icon-only
view actions. Feedback flashes over the chart and never moves content. The
fixture is synthetic and visibly labeled; no private attachment, live printer
value or local attachment path is committed.

Browser acceptance uses the actual private-handler response for paired 2D/3D
captures at 320, 390, 590 and 720 CSS pixels, equal chart `DOMRect`, 44-pixel
controls, no overflow, no console error and no nonlocal request. The exact lab
route is excluded from the dashboard directory and MCP resources, and public
HTTP returns 404. These fixture captures are software/design evidence, not a
focused production cutover, live-printer observation or user-device acceptance.
